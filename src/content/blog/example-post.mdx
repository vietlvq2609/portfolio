## Structure

Use standard Markdown for prose, and fenced code blocks for snippets — they're highlighted at
build time with Shiki, no client-side JS required:

```ts
export function memoize<T extends (...args: never[]) => unknown>(fn: T): T {
  const cache = new Map<string, ReturnType<T>>();
  return ((...args: Parameters<T>) => {
    const key = JSON.stringify(args);
    if (!cache.has(key)) cache.set(key, fn(...args) as ReturnType<T>);
    return cache.get(key);
  }) as T;
}
```

<Note>Use `Note` for callouts that shouldn't look like regular prose — caveats, gotchas, or context.</Note>

## Frontmatter reference

- `title`, `description` — used in listings, SEO, and OG tags
- `pubDate` — ISO date, drives sort order
- `tags` — must come from the fixed enum in `src/content.config.ts`
- `draft` — `true` hides the post from all public listings and RSS
