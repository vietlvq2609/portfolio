A personal Node.js project (ongoing) built to learn distributed-systems concepts through
hands-on implementation, rather than through tutorials alone.

## What it covers

- Background workers and message queues for asynchronous file processing
- Splitting responsibilities across microservices
- Docker for local development and service isolation
- Nginx configuration for routing between services

It's a vehicle for self-teaching cloud deployment and infrastructure concepts — expect it to
keep evolving as new pieces are added.
